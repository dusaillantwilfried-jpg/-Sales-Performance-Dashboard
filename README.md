# Sales Performance Dashboard

## Overview
This project demonstrates how sales data can be transformed into actionable business insights using Power BI.

The dashboard is designed from a Sales Manager perspective, with a focus on commercial performance, profitability and decision-making.

## Business Objectives
- Monitor revenue and sales growth
- Track gross margin and profitability
- Identify top-performing customers and products
- Compare regional performance
- Detect sales opportunities and performance gaps
- Support data-driven commercial decisions

## Key KPIs
- Revenue
- Sales Growth %
- Gross Margin
- Margin %
- Sales Volume
- Customer Performance
- Product Performance
- Regional Performance

## Tools
- Microsoft Power BI
- Microsoft Excel
- Data modelling
- DAX
- Data visualization
